# Warehouse

Локальное настольное приложение для будущего учёта склада. Сейчас это чистый
шаблон: главная страница, настройки темы и информация о приложении. Складские
операции и сервер в эту версию не входят.

## Запуск

Нужны Node.js 24 и npm. Из корня репозитория:

```sh
npm ci
npm run dev
```

Режим разработки запускает Vite на `http://127.0.0.1:5174`, собирает preload
и открывает Electron. Чтобы включить инструменты разработчика в PowerShell:

```powershell
$env:WAREHOUSE_DEVTOOLS = '1'
npm run dev
```

Для сборки и запуска локального интерфейса выполните `npm start`.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Разработка с Electron и Vite |
| `npm start` | Сборка и запуск приложения |
| `npm run build` | Сборка renderer и preload в `build` |
| `npm test` | Автоматические проверки |
| `npm run check` | Автоматические тесты и сборка |
| `npm run test:desktop` | Проверка настоящего Electron, preload, IPC и SQLite |
| `npm run icons` | Генерация PNG и ICO из исходной SVG-иконки |
| `npm run pack:win` | Упаковка Windows без установщика |
| `npm run build:win` | Сборка Windows NSIS и portable |

Артефакты упаковки находятся в `release`. Для Windows-сборок используйте Windows.
Иконки генерируются установленным Electron; отдельный графический конвертер не нужен.

## Данные

База автоматически создаётся в `app.getPath('userData')/data/warehouse.sqlite`.
Приложение показывает фактический путь и статус SQLite в настройках. Сейчас база
хранит только тему; выбор сохраняется между запусками. Данные Warehouse отделены
от Work Board. При ошибке интерфейс показывает сообщение и возможность повтора.

## Структура

- `src/main` — окно Electron, IPC, сервисы и репозитории SQLite.
- `src/renderer` — Vue-страницы, оболочка, Pinia и клиентские сервисы.
- `src/shared` — каналы, контракт bridge и валидация.
- `src/public/icons` — исходная SVG-иконка и необходимые PNG/ICO.
- `scripts` — запуск, проверки и подготовка сборки.
- `tests` — автоматические проверки.

Стек: Electron 38.8.6, Vue 3.5.44, Vite 7.3.7, Pinia 3, Tailwind CSS,
Lucide и встроенный `node:sqlite`. Подробнее о границах модулей и добавлении
функций — в [описании архитектуры](docs/architecture.md).

Зависимости, сборки, локальные базы, результаты проверок и рабочие планы агентов
исключены из Git. Файл `package-lock.json` фиксирует зависимости для `npm ci`.
